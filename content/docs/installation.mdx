Rós Madair is a Rust workspace. The current stack is eight crates:

| Crate | Purpose |
|-------|---------|
| `ros-madair-handlers` | Datatype → index-class classification; the CLM `reference` handler |
| `ros-madair-format` | The snapshot contract (manifest + `FORMAT_VERSION` + snapshot-id derivation) and attestation **verify**; held to `wasm32` |
| `ros-madair-query` | The typed `Query`/`Expr` IR + `ModelCatalog` (discovery) and `explain` — backend-agnostic, no compiler |
| `ros-madair-compile` | The pure `Query` IR → DuckDB SQL compiler (`compile_expr`/`compile_query`); no libduckdb, builds for `wasm32` |
| `ros-madair-emit` | CLI/library: compile a data directory into the tile-row + edge Parquet substrate + concept catalog + manifest; `sign`/`verify`/`pubkey` |
| `ros-madair-duck` | Native executor of the compiled SQL over Parquet; tile-graph hydration, overlay, `cited_by`, and reader-side snapshot verify |
| `ros-madair-wasm` | Browser runtime: wraps `ros-madair-compile` behind wasm-bindgen; published to npm as `ros-madair` |
| `ros-madair-python` | PyO3 bindings (over `duck`) |

## Prerequisites

- **Rust** (stable) — [rustup.rs](https://rustup.rs/)
- **Python 3.10+** — only for the PyO3 bindings (`ros-madair-python`).

## The alizarin sibling checkout

Every crate depends on
[`alizarin-core`](https://github.com/flaxandteal/alizarin) via a relative path.
The alizarin repository must be checked out as a sibling directory alongside the
parent `magic/` directory:

```
magic/
  alizarin/                     # <- clone here
  RosMadair-sandbox-parquet/    # this repo
```

## Build and test

```bash
cargo build --release
cargo test --workspace
```

## Python bindings (optional)

```bash
pip install maturin
maturin develop -m crates/ros-madair-python/Cargo.toml
```

This produces an importable extension module exposing the `duck`-backed reader
(`Graph` + `Reader`: resolve, count, resource tiles, hydrate).

## Documentation site

These docs live in the separate
[`ros-madair-docs`](https://github.com/flaxandteal/ros-madair-docs) repository,
built with [Fumadocs](https://fumadocs.dev/) on Next.js — the same machinery and
theme as the [alizarin docs](https://github.com/flaxandteal/alizarin-docs):

```bash
npm install
npm run dev      # local preview at http://localhost:3000
npm run build    # static export in out/
```
